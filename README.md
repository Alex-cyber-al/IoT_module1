## 🏗️ 4-Рівнева архітектура системи
Проєкт реалізує повний стек побудови IoT-інфраструктури для розумної квартири:

1. **Рівень пристроїв (Perception Layer):** Локальний симулятор на Python (`simulator/devices.py`), який імітує роботу датчика лічильника електроенергії (Вт), датчиків руху для двох кімнат, а також сенсорів температури та вологості.
2. **Мережевий рівень (Network Layer):** Брокер повідомлень Eclipse Mosquitto, розгорнутий у Docker-контейнері. Маршрутизація даних відбувається за протоколом MQTT у форматі JSON-пакетів з мітками часу `ts`.
3. **Рівень інтеграції (Middleware Layer):** Платформа openHAB, яка через модуль MQTT Binding та профілі трансформації JSONPATH автоматично розбирає вхідні топіки телеметрії.
4. **Рівень додатків (Application Layer):** Автоматизовані сценарії openHAB Rules (Rule DSL) та графічний інтерфейс користувача Sitemap (Basic UI) для моніторингу та захисту мережі від перевантажень.

## 🛡️ Безпека системи та модель загроз STRIDE
У Mosquitto повністю заблоковано анонімний доступ (`allow_anonymous false`), активовано автентифікацію за SHA-512 хешами паролів та налаштовано матрицю доступу ACL за принципом найменших привілеїв (сенсори мають права виключно на `write`).


| Загроза (STRIDE) | Опис для створеної системи | Захід протидії в проєкті |
| :--- | :--- | :--- |
| **S**poofing (Підміна) | Зловмисник підміняє датчик руху та надсилає фейкові дані. | Вимкнено анонімний доступ, увімкнено автентифікацію для пристроїв. |
| **T**ampering (Модифікація) | Перехоплення та несанкціонована зміна Ватів лічильника в мережі. | Конфігурація підтримує роботу на захищеному TLS порту 8883. |
| **R**epudiation (Відмова) | Користувач заперечує ручне вимкнення автоматики або обігрівача. | Логування всіх системних подій у журналі подій openHAB та брокера. |
| **I**nformation Disclosure | Витік даних про присутність людей у квартирі з відкритих топіків. | Налаштовано правила `acl.conf` для жорсткої ізоляції топіків кімнат. |
| **D**enial of Service | DoS-атака на брокер для зупинки роботи критичної автоматики. | Ізоляція мережі всередині Docker Bridge та обмеження рестартів контейнера. |
| **E**levation of Privilege | Звичайний сенсор намагається надіслати команду вимкнення пристроїв. | Жорсткі права в ACL: користувачу `sensor_user` дозволено виключно WRITE. |


## 🚀 Інструкція з розгортання (IaC)
Проєкт запускається однією командою на будь-якому ПК:

1. Розгорнути інфраструктуру контейнерів:
   ```bash
   docker compose up -d
   ```
2. Запустити локальний симулятор квартири на Python:
   ```bash
   py simulator/devices.py
   ```
